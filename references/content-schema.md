# Схема content.json

Единственный источник данных для рендера. Claude заполняет этот JSON из свободного
описания пользователя и передаёт файл в `scripts/generate.js`. Не добавляй полей
сверх схемы — неизвестные поля игнорируются рендером.

Если данных для поля нет и оно не помечено ниже как «опционально» — не выдумывай
значение. Поставь строку `"TBD"` (для строк) и обязательно предупреди пользователя
в чате, какие разделы нужно дополнить. Числовые обязательные поля (например, цены)
без данных лучше вообще не включать в `items`/`total` и явно спросить пользователя,
чем проставлять 0 или выдуманную цифру.

## Верхний уровень

| Поле | Тип | Обязательно |
|---|---|---|
| `meta` | object | да |
| `cover` | object | да |
| `problem` | object | да |
| `solution` | object | да |
| `scope` | object | да |
| `timeline` | object | опционально |
| `pricing` | object | да |
| `cases` | object | опционально |
| `terms` | object | опционально |
| `contacts` | object | да |
| `outputSlug` | string | да — короткий латинский slug для имени папки вывода, например `"romashka-delivery-app"` |

## `meta`
```
{
  "clientName": "ООО «Ромашка»",
  "projectTitle": "Мобильное приложение доставки",
  "date": "2026-08-02",           // ISO-дата, если не указана — сегодняшняя
  "proposalNumber": "KP-2026-014", // опционально, можно "TBD"
  "preparedBy": "Агентство «Вектор»"
}
```

## `cover`
```
{
  "title": "Заголовок обложки — обычно = projectTitle или ярче",
  "subtitle": "Одна фраза о ценности предложения для клиента"
}
```

## `problem` и `solution`
Одинаковая форма для обоих:
```
{
  "heading": "Задача" | "Решение",
  "body": "1-2 абзаца свободного текста",
  "points": ["короткий тезис 1", "короткий тезис 2"]  // опционально, 2-5 штук
}
```

## `scope`
```
{
  "heading": "Этапы работ",
  "stages": [
    { "title": "Этап 1. Аналитика и дизайн", "description": "...", "result": "Кликабельный прототип" },
    { "title": "Этап 2. Разработка", "description": "...", "result": "Рабочее приложение" }
  ]
}
```
Минимум 1 этап. Обычно 3-6.

## `timeline` (опционально, но желательно)
```
{
  "heading": "Сроки",
  "totalDuration": "8 недель",
  "milestones": [
    { "label": "Этап 1. Аналитика и дизайн", "duration": "2 недели" },
    { "label": "Этап 2. Разработка", "duration": "4 недели" }
  ]
}
```

## `pricing`
```
{
  "heading": "Стоимость",
  "currency": "₽",
  "items": [
    { "title": "UX/UI-дизайн", "description": "...", "price": 150000 },
    { "title": "Разработка", "description": "...", "price": 550000 }
  ],
  "total": 700000,
  "packages": [   // опционально, если предложены тарифы вместо одной сметы
    { "name": "Базовый", "price": 500000, "includes": ["...", "..."] },
    { "name": "Расширенный", "price": 850000, "includes": ["...", "..."] }
  ]
}
```
Либо `items` + `total`, либо `packages` — можно и то, и другое. Если стоимость не
известна, оставь `items: []`, `total: "TBD"` и обязательно спроси пользователя.

## `cases` (опционально)
```
{
  "heading": "Наши кейсы",
  "items": [
    { "title": "Название проекта", "description": "...", "result": "Метрика/результат" }
  ]
}
```
Если пользователь не упоминал портфолио — просто не включай `cases` в JSON, слайд
пропустится автоматически.

## `terms` (опционально)
```
{
  "heading": "Условия",
  "paymentTerms": "50% предоplата, 50% по факту сдачи этапа",
  "validUntil": "2026-09-01",
  "notes": "Любые доп. условия одной строкой"
}
```

## `contacts`
```
{
  "heading": "Контакты",
  "personName": "Иван Петров",
  "role": "Руководитель проектов",
  "phone": "+7 999 123-45-67",
  "email": "ivan@agency.ru",
  "messenger": "@ivan_agency",
  "cta": "Готовы начать на этой неделе — напишите нам"
}
```
Нужен хотя бы один канал связи (`phone`, `email` или `messenger`).

## Правила для Claude при сборке JSON

1. Разделы, отмеченные «опционально» и не упомянутые пользователем — не включать
   в JSON вовсе (не заполнять пустышками).
2. `scope.stages` и `contacts` — минимальный набор, без которого КП не имеет смысла;
   если их нечем заполнить, сначала спроси пользователя, не запускай рендер.
3. Тон текста — деловой, без канцелярита и без чрезмерного маркетингового пафоса
   (подробнее — `kp-writing-guide.md`).
4. Перед запуском `scripts/generate.js` файл `content.json` должен пройти
   `scripts/validate-content.js` (вызывается автоматически внутри `generate.js`).
